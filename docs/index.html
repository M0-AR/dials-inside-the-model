🌱 Beginner Guide — read this and you are a professional

The kitchen story. A tiny model starts a story in a kitchen: "the chef bakes a pan". We turn one dial — the snow dial — and it writes "a penguin and a climber likes the glacier". Nothing else broke. That dial was never programmed. It was found.

Let's work this out in a step-by-step way to be sure we have the right answer:

1. Words → numbers. Every word becomes 12 numbers. Eight words = 96 numbers.
2. Neurons. 24 little units add things up; negatives become zero. Everything the model knows right now must squeeze through these 24.
3. The problem. The model tracks 12 topics + 7 kinds of next word + sentence position — far more than 24 slots. So it shares: one neuron helps many ideas; one idea spreads over many neurons. That is polysemanticity.
4. Why sharing works. Ideas are rare (snow only 1 time in 12). Rare ideas can overlap like 5 arrows sharing a sheet of paper in a pentagon — small overlaps fall under a threshold and vanish. That is superposition.
5. The tool. A sparse autoencoder asks: what few directions explain these dots? With the rule "only 3 may speak" (TopK), it recovers the true arrows.
6. Reading. A feature that fires 83% in sea sentences is the sea feature. One that fires before places is the place feature.
7. Turning. Add a feature's direction back into the model and you steer it — like the Golden Gate Bridge dial in Claude.
8. How many? Bigger dictionaries split ideas finer (snow → 17 pieces) and collect dead ones. There is no single right size, only zoom levels.

No background needed. If you can read the kitchen sentence above, you can run this repo.

Pipeline — 8 short programs

1. Model
188 words, 12 topics, 8-word context → 24 neurons → 188 scores. Surprise 5.24 → 0.98.
2. Neurons
Busy (45%), flat topic bars, 0/24 pure. Proof of tangle.
3. Superposition
5 ideas in 2 neurons form a pentagon at 10% sparsity.
4. SAE toy
Dense fails; TopK K=1 recovers arrows ≥0.989.
5. SAE real
64 atoms, K=3: 90.7% rebuild, swap keeps 98.3%.
6. Reading
12 topic + 36 next-word features, 16 unclear.
7. Steering
Snow 0.5× 73% → 1× 99.5% → 5× collapse. Features beat neurons 6–1.
8. Scaling
16→256: rebuild 78.7→95.6%, snow 1→17, dead 0→51.
